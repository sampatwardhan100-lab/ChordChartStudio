# Chord Chart Studio

A chord chart editor that runs in the browser as one file (index.html).

- Build charts with bars, chords, sections, tempo and repeats
- Sign in and share charts or setlists with other musicians
- Export to PDF, JPG, text and ChordPro
- Import charts from PDF, MusicXML (.musicxml, .xml, .mxl) and pictures (JPG, PNG)

Version 9.1

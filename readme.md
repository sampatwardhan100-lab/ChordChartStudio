# Chord Chart Studio

A chord chart editor and score reader that runs in the browser. The app is one file (`index.html`); the other files in this folder are its icons, install manifest, and the privacy and terms pages.

- Build charts with bars, chords, sections, tempo and repeats; type chords quickly, or write them with a stylus
- Import charts from PDF, MusicXML, Guitar Pro, MIDI, text and pictures, or keep a PDF or photo exactly as it is
- PDF scores: full-screen reader, single or two-page view, crop, night mode, bookmarks, and Apple Pencil notes
- Setlists with a full-screen Perform mode, page-turn pedals and half-page turns
- Practice audio with loops, a tempo trainer and a waveform editor
- Sign in and share charts or setlists with your band, with live editing and private notes
- Export to PDF, JPG, text and ChordPro

Version 11.0.2

Files in this folder: `index.html` (the app), `privacy.html`, `terms.html`, `manifest.webmanifest`, `icon-192.png`, `icon-512.png`, `icon-maskable-512.png`, `robots.txt`.
